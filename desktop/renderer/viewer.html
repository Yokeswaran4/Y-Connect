Control this phone with ADB

  1. On the phone: Settings → Developer options → Wireless debugging → turn it on.
  2. Tap Pair device with pairing code. Enter the address and 6-digit code it shows below (it is filled in when found).
  3. Press Pair & control. You only do this once per computer.
Needs adb (Android platform-tools) on this computer. Over USB: enable USB debugging and plug the phone in, then press Connect.
